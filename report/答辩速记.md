## 二、五个概念，每个一句话

| 概念 | 一句话 |
|---|---|
| 成五点集 W(p,c) | 我在 p 落子后，"再落一子就成五"的空点集合；用它的**个数**区分冲四（1个）和活四（≥2个） |
| 威胁分级 | 成五1000万 / 活四100万 / 冲四10万 / 活三1万 / 眠三1千 / 活二100，**10倍一跳**保证高等级压倒任意多低等级 |
| 候选裁剪 | 只考虑棋子周围 2 格内的空点；因为一步成五的点旁边必有己方棋子（可现场证明） |
| Alpha-Beta | 明显不会更好的分支直接剪掉；理想情况节点数从 b^d 降到 b^(d/2) |
| VCF | 连续冲四，对手每步只有唯一应手，攻击链没有分岔，所以几千节点就能证明必胜 |

## 四、最可能被问的 8 个问题

**Q1 你的 AI 怎么决定走哪一步？**
按六步流水线：先看能不能一步赢，再看对手是不是马上要赢必须堵，然后算能不能连续冲四将死、能不能一手造双威胁、对手有没有活三；都没有才进入深度搜索。

**Q2 怎么评价一个局面好坏？**
把棋型分成等级给分，成五1000万、活四100万、冲四10万、活三1万，每级差10倍。关键设计是10倍刻度，保证一个冲四一定大于任意多个活二，AI 不会贪小失大。

**Q3 为什么 Alpha-Beta 快？**
它维护一个"我已经能保证拿到的分数"和"对手不会让我超过的上限"，一旦某个分支算出来比上限还好，说明对手不会允许走到这里，剩下的就不用看了。理想情况计算量从 b 的 d 次方降到 b 的 d/2 次方，等于同样时间多搜一倍深度。

**Q4 VCF 是什么？**
连续冲四。我每一步都冲四，对手只有一个合法应手必须堵，所以这条攻击链上没有分岔——我只要试自己的几种冲四顺序，不用管对手想怎么走。几千个节点就能证明"我几步之内必胜"。

**Q5 为什么只考虑棋子周围两格？**
因为要成五必须有4颗子已经在一条线上。这4颗子无论怎么分布，离落点最近的那颗距离一定不超过2格。所以裁掉两格外的点不会漏掉任何"一步成五"的点。裁完候选点从225个降到几十个，搜索才跑得动。

**Q6 三档难度怎么做的？**
同一套算法，只调四个参数：搜索深度（3/6/12）、每手时限（0.15/0.95/3秒）、战术开关（VCF和防守关掉就是弱）、失误率（普通档15%概率不选最优）。实测普通人胜率分别是56%、33%、12.5%。

**Q7 为什么普通难度会输？**
只搜3层，看不到"活三→活四→成五"的三步杀；而且不主动防活三，还有15%概率随手走。但所有难度都一定堵五连——否则看起来像程序坏了。

**Q8 你这套有什么不足？**
三个：①Python 太慢，深度只到4层，换 C++ 同样3秒能到8~10层；②开局偏弱，搜索型AI缺乏棋理；③估值表靠手工标定。
